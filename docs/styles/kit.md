# `kit`

The channel's own palette (`DEFAULT_PALETTE`) on the shared gradient Backdrop. The default: an old video with no `style` renders exactly as before.

- **Use for:** anything; the house look
- **Avoid for:** nothing; switch only when the topic asks for a different world
- **Accent:** cyan #3FD0FF — only the hero / the number the voice is saying (§6).
- **Caption:** white on a black 10 px outline, uppercase
