# `paper`

Warm paper, ink and a vermilion accent (look `paper`). Light page.

- **Use for:** editorial, humanities, history, quotes
- **Avoid for:** night scenes, space
- **Accent:** vermilion #e5432d, green garnish — only the hero / the number the voice is saying (§6).
- **Caption:** ink-dark outline (palette.deep) on light page; check contrast on stills
